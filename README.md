# 想记（WantNote）

Android 速记应用。包名：`com.davidzhu.wantnote`

## 0.7.0

在 0.6.0 之上：修复坚果云 WebDAV「测试并保存」因请求被改写成 POST 而返回 501 的问题，改用 OkHttp 发送真正的 PROPFIND / MKCOL / PUT / GET；设置里的「云同步」改为「备份与同步」，分「备份」「云同步」两个 Tab，新增一键 zip 备份与结构化恢复（笔记、块、标签、笔记-标签、附件/媒体、自定义字体、全部设置与 AI 提供商）；新增「导入与导出」子菜单，支持单个或多个 .md / .markdown / .html / .htm 及 zip 导入（含进度、逐文件中文报错、zip 内图片/附件拷贝），并支持把全部笔记导出为 Markdown（多篇或含附件时打包 zip，单篇无附件直接保存 .md）。

## 0.6.0

在 0.5.0 之上：保存后的标签会持久化，并在各主页视图和再次进入编辑时外露；WebDAV 连接测试与坚果云兼容，错误只给简短中文说明，不展示原始 XML；编辑器点返回会立刻把当前标题和正文落盘再退出；本地数据库和附件优先放在用户可见的 Documents/WantNote，授权存储后卸载重装可还原（未授权时仍用应用私有目录）；官方包使用固定正式签名。

## 0.5.0

在 0.4.0 之上：主页卡片、瀑布流、极简、时间戳四种视图的笔记卡片都带可见的柔和立体投影；编辑器工具栏新增「#」标签按钮，可手动选择/取消已有标签，也能直接输入并新建标签（可选颜色）后附加到笔记；「保存」按钮的 AI 标题/标签改为“只补空位”：在生成结果应用时逐项检查，标题和标签各自独立，只填充仍然为空的字段，绝不覆盖已写好的标题或标签（包括 AI 请求进行中用户手动做的修改）；设置 → 标签管理的颜色选择改为紧凑的单行色条（选中带圈环与对勾）；洞察拆成「回顾」与「总结」两页：回顾支持日期范围（本周/本月/近7天/近30天/全部/自定义起止日）与标签筛选，总结支持按日/按周/按月/按标签/按主题五种范围，AI 提炼沿用原有流程，只对当前范围的笔记做提炼；AI 设置的默认模型选择改为下拉框，列出各提供商已获取的模型（已勾选的排前）。数据库从 v4 平滑迁移到 v5（仅新增 aiSummaryScope 列），笔记、标签、附件与云同步均不受影响。

## 0.4.0

在 0.3.0 之上：编辑器增加「保存」按钮，按下时才由 AI 生成标题和标签（离开编辑器仍会自动保存正文，但不再触发 AI）；去掉编辑器顶部的手动新建标签和颜色框，改为选择已有标签；设置改为两级菜单（通用设置、编辑器设置、标签管理、附件管理、云同步、AI设置、关于）。编辑器可选用内置免费字体（Noto Sans SC、Noto Serif SC、Inter、JetBrains Mono）或添加自定义 TTF/OTF；标签可在设置里增删查改、设色和添加子标签；附件管理按文件/图片/视频分栏，可清理无引用附件，并保留图片压缩、增加视频压缩开关。云同步支持 WebDAV 与 S3 的测试并保存、实际上传和下载（按更新时间合并，不删除未出现在远程清单中的本地笔记）。关于页展示 logo、口号「想记，想记就记！」和版本号，并可通过 GitHub 检查更新。

## 0.3.0

在 0.2.0 之上：主页四种视图对图/视频显示缩略图；编辑器去掉「大纲」、实时显示字数；多级标签（斜杠路径 + 颜色）；主页搜索支持关键字/标签/日期；设置增加 AI 接入（DeepSeek、智谱、Kimi、阿里云百炼、千问、自定义：填 key、一键拉模型再勾选）；提炼总结与保存时自动标题/标签走所选模型。未填 key 时本地功能仍可用。本包申请 INTERNET，云同步仍只保存配置。

## 0.2.0

底栏五页：主页、日历、中间加号新建、洞察、设置。编辑器改为大纲编辑器，工具栏含任务、有序/无序列表、分割线、字号、粗细、斜体、删除线、高亮、缩进/反缩进、本地图片和视频。本地离线保底；云同步（WebDAV / S3）本包只保存配置，不实际上传下载，也不申请网络权限。

上一档 V0（打开即写、时间流、搜索、基础格式、本地离线）继续保留。0.1.0 已有笔记会在升级时导入为大纲段落节点。
