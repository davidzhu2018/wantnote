# 想记（WantNote）

Android 速记应用。包名：`com.davidzhu.wantnote`

## 0.20.0
- 主页下拉筛选器新增「置顶」与「星标」两个选项；主页 5 种视图均升级为 50 条懒加载分页（上滑接近底部自动续载）；多选底部胶囊新增「取消」按钮直接退出多选并隐藏胶囊。
- 导入（5 入口）、生态互联（Dinox / Readwise / 微信读书全量与增量同步）以及备份、恢复与云同步全面接入进度条与实时进度提示。
- 微信读书单向同步修复为官方微信读书 Skill Agent 网关（`POST https://i.weread.qq.com/api/agent/gateway`，携带 `Authorization: Bearer <API_KEY>` 与 `skill_version: 1.0.6`），支持游标分页拉取划线、高亮与个人想法并新增「验证连接」。
- Readwise 同步支持「沿用 Readwise 分类名（自动创建/匹配卡片盒）」，并支持为每个分类设置同步标签（默认 `#Readwise`，可选择已有或新建标签）。
- 洞察页全面升级：总结支持一键将 AI 提炼/洞察/日报/周报保存为笔记，并新增「AI 日报」（当天笔记汇总）与「AI 周报」（本自然周笔记汇总）；回顾改为按条件随机抽取 20 条左右滑动卡片图集，回顾完成后自动标记「已回顾」并支持「再来一批」（优先未回顾）；图谱在 2D 点线视图之外新增可拖动旋转与缩放的 3D 立体星云视图。
