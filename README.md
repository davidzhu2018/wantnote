# 想记（WantNote）

Android 速记应用。包名：`com.davidzhu.wantnote`

## 0.4.0

在 0.3.0 之上：编辑器增加「保存」按钮，按下时才由 AI 生成标题和标签（离开编辑器仍会自动保存正文，但不再触发 AI）；去掉编辑器顶部的手动新建标签和颜色框，改为选择已有标签；设置改为两级菜单（通用设置、编辑器设置、标签管理、附件管理、云同步、AI设置、关于）。编辑器可选用内置免费字体（Noto Sans SC、Noto Serif SC、Inter、JetBrains Mono）或添加自定义 TTF/OTF；标签可在设置里增删查改、设色和添加子标签；附件管理按文件/图片/视频分栏，可清理无引用附件，并保留图片压缩、增加视频压缩开关。云同步支持 WebDAV 与 S3 的测试并保存、实际上传和下载（按更新时间合并，不删除未出现在远程清单中的本地笔记）。关于页展示 logo、口号「想记，想记就记！」和版本号，并可通过 GitHub 检查更新。

## 0.3.0

在 0.2.0 之上：主页四种视图对图/视频显示缩略图；编辑器去掉「大纲」、实时显示字数；多级标签（斜杠路径 + 颜色）；主页搜索支持关键字/标签/日期；设置增加 AI 接入（DeepSeek、智谱、Kimi、阿里云百炼、千问、自定义：填 key、一键拉模型再勾选）；提炼总结与保存时自动标题/标签走所选模型。未填 key 时本地功能仍可用。本包申请 INTERNET，云同步仍只保存配置。

## 0.2.0

底栏五页：主页、日历、中间加号新建、洞察、设置。编辑器改为大纲编辑器，工具栏含任务、有序/无序列表、分割线、字号、粗细、斜体、删除线、高亮、缩进/反缩进、本地图片和视频。本地离线保底；云同步（WebDAV / S3）本包只保存配置，不实际上传下载，也不申请网络权限。

上一档 V0（打开即写、时间流、搜索、基础格式、本地离线）继续保留。0.1.0 已有笔记会在升级时导入为大纲段落节点。
